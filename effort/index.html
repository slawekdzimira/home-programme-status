How these numbers were produced. Pull request and commit figures are read from the Azure DevOps API for the eleven program repositories (ERP, DMS, DMS.UI.Tenant, lobby, hotma-engine, semap-engine, CRRA-engine, BHC, hcv-board-sync and the two automated test repositories), window 5 August to 15 September 2026 inclusive, extracted on 15 September 2026. Commits are counted once per author and timestamp across all feature branches; automated identities (build service, sync pipeline, QA autopilot) are excluded. Working time is the span from the first to the last code event of each engineer on each day plus one hour, so it excludes days spent on design, review, testing or meetings without a commit. Lines of code compare the main branch on the last commit before 5 August with today, counting source and configuration files only (no documentation, data or lock files, no dependencies). Test cases are counted as test functions in test files. Review comments exclude system notes; the AI reviewer and build service are counted separately from engineers. A review round is one pull request iteration after the first push. Working days are Monday to Friday; local time is Central European Summer Time. Board figures come from the HCV Team board export of the same day.
